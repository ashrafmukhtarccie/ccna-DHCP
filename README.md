

# DHCP Configuration

## Overview

This lab demonstrates how DHCP can automatically provide IP configuration to network devices.

## Objectives

* Configure DHCP pools
* Configure address exclusions
* Assign default gateways
* Verify DHCP leases
* Test client connectivity

## Tools

* Cisco Packet Tracer
* Cisco IOS

## Outcome

Configured DHCP and successfully assigned network parameters to clients.
